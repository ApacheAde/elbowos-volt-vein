# Volt Vein

Full-colour Python 3 neon light-cycle arcade for ElbowOS.

Steer a cyan cycle through a dark void.
Leave a bright trail. Avoid walls, your own path, and rival cycles.
Scoop gold orbs for bonus score.

WASD / arrows to steer.

## Play

```bash
pip install -r requirements.txt
python3 volt_vein.py --play
```

## Record a 9:16 reel

```bash
python3 volt_vein.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
